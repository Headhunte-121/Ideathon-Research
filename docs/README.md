## How to read these documents

- **Reports are the source of truth.** They record results from simulation and public recordings, including failures.
- **Design, research and competition documents describe intent.** Many were written before testing. They contain proposed features, targets and figures from the literature that this project has not verified. Do not read them as measured performance.
