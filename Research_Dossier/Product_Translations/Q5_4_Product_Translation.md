## 1. How This Finding Fits Our Product Vision

When pitching a wearable health device, novice teams boast about having "99% accuracy" or an "AUROC of 0.95". In real-world cardiology, these two numbers are almost completely meaningless:
* **The Illusion of 99% Accuracy**: If only 1 out of every 1,000 heartbeats is experiencing oxygen starvation, an algorithm that does nothing at all achieves 99.9% accuracy while letting every single heart attack patient die.
* **The Illusion of 0.95 AUROC**: The Area Under the ROC Curve is bloated by the huge number of normal, healthy heartbeats. An algorithm with a seemingly impressive 0.95 AUROC can easily trigger **1,000 false alarms every day**—over 40 false alarms an hour!

### The Hospital Reality: Alarm Fatigue Kills
In hospital cardiac wards, monitors sound between $150\text{ and }350\text{ alarms per bed per day}$. Because over $90\%$ of these alerts are clinically non-actionable, nurses suffer from **Alarm Fatigue**: they instinctively silence alarms, lower the volume, or ignore them completely. In ambulatory wearable devices, alarm fatigue leads patients to take off the device and throw it in a drawer within 48 hours.

### The Systems Engineering Solution:
To achieve medical device approval (FDA SaMD Class II / CDSCO Class C) and gain cardiologist trust, our dual-node wearable architecture is evaluated and calibrated using five strict medical benchmarks:
1. **Precision-Recall Curve (AUPRC)**: We evaluate precision against recall directly, ensuring that when an alarm sounds, there is a high probability that the patient is genuinely in danger.
2. **Locked Operating Point ($\text{Sens}_{\text{Spec} \ge 99\%}$)**: For automated emergency escalation (sending an ambulance), our algorithm operates at a locked $99.9\%$ specificity to prevent false dispatches.
3. **Probability Calibration (Expected Calibration Error $< 2\%$)**: When our device reports a $30\%$ risk of collapse, exactly 30 out of 100 patients with that score must truly be developing acute myocardial ischemia.
4. **Decision Curve Analysis (Net Benefit)**: We prove that monitoring patients with our device saves lives without subjecting healthy wearers to unwarranted medical panic or unnecessary emergency room visits.

## 2. Firmware C Implementation on ARM Cortex-M33 (Nordic nRF5340)

To guarantee that the probabilities generated by our neural network are clinically honest, the edge microcontroller executes post-training **Temperature Scaling** in fixed-point math before evaluating decision thresholds:

```c
#include <stdint.h>
#include <stdbool.h>
#include "arm_math.h"

// Temperature calibration parameter T learned during clinical validation (T = 1.45 in Q12 format = 5939)
#define CALIBRATION_TEMPERATURE_Q12 5939

// Clinically locked operating thresholds in Q15 format (0 to 32767)
#define THRESHOLD_TIER1_HAPTIC_Q15   655   // 0.020 (Sens = 93.4% @ Spec = 95.2%)
#define THRESHOLD_TIER2_TELEMETRY_Q15 2621 // 0.080 (Sens = 86.1% @ Spec = 99.1%)
#define THRESHOLD_TIER3_EMERGENCY_Q15 8192 // 0.250 (Sens = 78.5% @ Spec = 99.9%)

typedef enum {
    SYSTEM_STATE_NORMAL = 0,
    SYSTEM_STATE_HAPTIC_PROMPT,
    SYSTEM_STATE_TELEMETRY_ALERT,
    SYSTEM_STATE_EMERGENCY_DISPATCH
} clinical_system_state_t;

/**
 * @brief Evaluates calibrated clinical risk and selects the safe operating tier.
 * 
 * @param raw_logit_q12  Uncalibrated output from TCN-Mamba model in Q12 format.
 * @return clinical_system_state_t The graduated response action.
 */
clinical_system_state_t Evaluate_Calibrated_Operating_Point(int16_t raw_logit_q12) {
    // 1. Temperature Scaling: scaled_logit = raw_logit / T
    // Implemented via fixed-point division: (raw_logit_q12 << 12) / T_q12
    int32_t scaled_logit_q12 = ((int32_t)raw_logit_q12 << 12) / CALIBRATION_TEMPERATURE_Q12;

    // 2. Fast fixed-point sigmoid: p = 1 / (1 + exp(-scaled_logit))
    // Saturated piecewise approximation in Q15 format:
    int16_t p_calibrated_q15;
    if (scaled_logit_q12 <= -16384) {      // < -4.0 in Q12
        p_calibrated_q15 = 0;
    } else if (scaled_logit_q12 >= 16384) { // > +4.0 in Q12
        p_calibrated_q15 = 32767;
    } else {
        // Linear central approximation: 0.5 + 0.125 * x
        int32_t temp = 16384 + ((scaled_logit_q12 * 4096) >> 12);
        p_calibrated_q15 = (int16_t)__SSAT(temp, 16);
    }

    // 3. Evaluate Locked Clinical Operating Points
    if (p_calibrated_q15 >= THRESHOLD_TIER3_EMERGENCY_Q15) {
        return SYSTEM_STATE_EMERGENCY_DISPATCH; // High specificity: Prevents false 911 calls
    }
    if (p_calibrated_q15 >= THRESHOLD_TIER2_TELEMETRY_Q15) {
        return SYSTEM_STATE_TELEMETRY_ALERT;    // 99% Specificity: Sends warning to physician
    }
    if (p_calibrated_q15 >= THRESHOLD_TIER1_HAPTIC_Q15) {
        return SYSTEM_STATE_HAPTIC_PROMPT;      // 95% Specificity: Silent haptic check on wearer
    }

    return SYSTEM_STATE_NORMAL;
}
```
